# Claudio — 情绪对应选歌规则

## 时间段映射
- 早晨 (06:00 - 08:00) → 轻柔、温暖、积极
- 上午 (08:00 - 11:30) → 活力、专注、节奏适中
- 午休 (11:30 - 13:30) → 轻松、舒缓、愉悦
- 下午 (13:30 - 18:00) → 专注、提神、节奏感
- 傍晚 (18:00 - 20:00) → 放松、治愈、律动
- 深夜 (22:00 - 00:00) → 安静、氛围、慵懒
- 凌晨 (00:00 - 06:00) → 极简、空灵、低沉
